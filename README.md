# Geo-Sleuth Web — фото → місце й час

**Live:** https://aprowaz1-crypto.github.io/geo-sleuth-web/

Браузерний OSINT-інструмент для геолокації фото. Перетягни (або встав) знімок — і отримай координати, адресу, карту з супутником, положення сонця й напрямок тіней, погоду на момент зйомки, пам’ятки поруч, OCR-підказки та готовий звіт. Усе працює локально у браузері: саме фото нікуди не завантажується.

> Для глибокого аналізу (скайлайн, супутникові знімки, Street View, CLIP/DINOv2, OSM-геометрія) використовуй Python-скіл **geo-sleuth** в OpenCode. Веб-версія — швидкий перший крок і зручний польовий інструмент.

## Можливості

- **EXIF / GPS:** exifr + вбудований парсер JPEG/PNG/WebP/TIFF; координати, висота, точність, напрямок камери, дата/час, часовий пояс, камера, об’єктив, експозиція, ISO, орієнтація. Сирі метадані — у JSON.
- **Карта:** Leaflet з шарами «Темна», OSM, супутник Esri і топо; маркер, коло точності, сектор напрямку камери, повноекранний режим. Якщо Leaflet недоступний — резервна OSM-карта.
- **Сонце й тіні:** азимут і висота сонця на момент зйомки, напрямок тіней, схилення, фаза Місяця, полярна діаграма траєкторії, схід/захід, золота година, сутінки, тривалість дня.
- **Місце:** адреса через Nominatim, висота через Open-Meteo, часовий пояс, посилання на OSM / Google Maps / Wikipedia Nearby.
- **Погода:** архів або прогноз Open-Meteo на найближчу годину зйомки; хмарність і підказка, чи мали бути тіні.
- **Поруч:** статті Wikipedia у радіусі 10 км із фото та описами; об’єкти OpenStreetMap через Overpass (кілька дзеркал, повторна спроба).
- **OCR:** Tesseract.js у браузері, 19 мовних наборів, попередня обробка зображення. Автоматичний запуск, якщо GPS немає.
- **Підказки:** телефони, email, URL, координати, адреси, дати, номери авто, соцмережі, хештеги, назви — клік по чипу копіює значення.
- **Зворотний пошук:** Google Lens/Images, Yandex, Baidu, TinEye, Bing, SauceNAO, Karma Decay.
- **Звіт:** Markdown, JSON або копіювання — з координатами, адресою, EXIF, сонцем, погодою, Wikipedia, OSM, OCR і посиланнями.
- **Інтерфейс:** українська за замовчуванням + перемикач EN, світла/темна тема, адаптивна верстка, гарячі клавіші (Ctrl+V — вставити фото), PWA/офлайн-оболонка.
- **Приватність:** фото обробляється лише на пристрої; до мережі йдуть тільки координати для адреси/погоди/Wikipedia/OSM.

## Технології

Leaflet, exifr, Tesseract.js, heic2any — з CDN. Власні модулі: парсер EXIF, сонячна/місячна математика (NOAA-формули), Leaflet-обгортка, генератор звітів, i18n. Без збірки та бекенду.

## Локальний запуск

```bash
cd geo-sleuth-web
python3 -m http.server 8080
# відкрий http://localhost:8080
```

Для перевірки PWA і service worker використовуй `localhost` або HTTPS.

## Тести

```bash
# статичні тести (i18n, EXIF, сонце)
node --test tests/*.test.js

# браузерний smoke-тест (потрібен Playwright Chromium)
uv run --with playwright python tests/smoke.py
```

Smoke-тест завантажує синтетичне GPS-фото, перевіряє EXIF, карту, сонце, адресу, перемикачі мови/теми, повноекранний режим і відсутність горизонтального скролу на мобільному.
